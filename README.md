# WordPeek

Новое английское слово с переводом и объяснением — на экране блокировки, при
каждом взгляде на часы.

- `data/` — словарь и сборщик базы
- `ios/` — исходники iOS-приложения и виджета (Swift, SwiftUI, WidgetKit)
- `web/` — веб-прототип: та же логика ротации, работает в любом браузере

---

## Главное ограничение, о котором нужно знать сразу

**iOS не даёт приложениям события «экран включился».** Ни в фоне, ни в виджете,
ни через какой-либо публичный API. Это не сложность реализации — этого просто
нет в системе, и ни одно приложение в App Store так не умеет.

Что делает WordPeek вместо этого:

WidgetKit ограничивает не количество **показов** виджета, а количество
**перестроений расписания** — примерно несколько десятков в сутки. Но одно
расписание может содержать сколько угодно записей с разным временем. Поэтому
виджет за одно обновление отдаёт системе 288 записей с шагом 5 минут — сутки
вперёд. Дальше система показывает их сама, бесплатно.

Результат: слово меняется на каждой границе слота. Смотришь на часы — под ними
слово; смотришь через десять минут — уже другое. Разницу с «при каждом
включении» можно заметить, только если разблокировать телефон дважды в течение
одного слота.

Интервал настраивается: 2, 5, 10, 15, 30 или 60 минут.

Реализация — в [`WordProvider.swift`](ios/WordPeekWidget/WordProvider.swift).

## Веб-прототип

Открывается в браузере, в том числе на самом iPhone. Показывает макет экрана
блокировки с живыми часами, полную карточку слова, кнопки «знаю / учить» и
расписание слотов. Логика ротации — та же, что в Swift.

```bash
python data/build.py && python web/build.py
```

Готовый файл — `web/index.html`, самодостаточный: словарь встроен внутрь,
интернет не нужен.

## Сборка iOS-приложения

Нужен **Mac с Xcode**. С Windows iOS-приложение собрать нельзя — это
ограничение Apple, обойти его локально не получится. Варианты: чужой Mac,
аренда (MacinCloud), или облачная сборка (Codemagic, Xcode Cloud).

### Через XcodeGen (быстрее)

```bash
brew install xcodegen
cd ios && xcodegen generate && open WordPeek.xcodeproj
```

> **Если собираешь из терминала:** не указывай `-derivedDataPath` внутри
> `~/Documents` или `~/Desktop` — iCloud Drive синхронизирует эти папки и
> вешает на свежесозданные файлы расширенные атрибуты, из-за чего codesign
> падает с ошибкой «resource fork, Finder information, or similar detritus
> not allowed». Дефолтное расположение DerivedData (`~/Library/Developer/…`)
> безопасно; Xcode из GUI использует его сам.

### Вручную, без XcodeGen

1. Xcode → **File ▸ New ▸ Project ▸ iOS App**, имя `WordPeek`, интерфейс SwiftUI.
2. **File ▸ New ▸ Target ▸ Widget Extension**, имя `WordPeekWidget`, галочку
   «Include Live Activity» снять.
3. Перетащить в проект папки `Shared/`, `WordPeek/`, `WordPeekWidget/`.
   Для файлов из `Shared/` в инспекторе справа отметить **оба** таргета
   в Target Membership.
4. `WordPeek/Resources/words.json` добавить в Copy Bundle Resources **обоих**
   таргетов — виджет читает словарь из своего бандла, не из приложения.

### Обязательный шаг: App Group

Без неё виджет не увидит прогресс. На **обоих** таргетах:
**Signing & Capabilities ▸ + Capability ▸ App Groups**, добавить группу с тем же
идентификатором, что в [`SharedStore.swift`](ios/Shared/SharedStore.swift):

```
group.com.wordpeek.shared
```

Если идентификатор занят, поменяй его в обоих `.entitlements` и в
`SharedStore.appGroupID`. Приложение переживёт отсутствие App Group (упадёт на
локальное хранилище и покажет предупреждение на главном экране), но виджет
будет показывать одно и то же слово.

### Установка на телефон

Бесплатный Apple ID подойдёт: подпись действует 7 дней, потом нужно
переустановить. Платный Developer Program ($99/год) — год. Дальше на телефоне:
долгое нажатие на экран блокировки → **Настроить** → область под часами →
добавить виджет WordPeek.

## Как устроена ротация

Обычная система Лейтнера, четыре коробки:

| Коробка | Состояние | Вес в очереди |
|---|---|---|
| 0 | новое или «учить» | 4 |
| 1 | на повторении | 3 |
| 2 | почти выучено | 1 |
| 3 | выучено | 0 — уходит из ротации |

Очередь строится из слов с повторами по весу, перемешивается детерминированным
генератором и раздвигается так, чтобы одно слово не попадало в соседние слоты.
Виджет по этой очереди ничего не вычисляет и ничего не пишет: время однозначно
отображается в слот, слот — в слово. Поэтому сутки расписания строятся за один
проход.

Когда все слова доходят до коробки 3, очередь не пустеет — включается лёгкий
режим повторения.

## Словарь

1000 слов: A2 — 180, B1 — 320, B2 — 300, C1 — 200. У каждого слова транскрипция,
часть речи, перевод, английское определение, 2–3 примера с переводом и заметка
о типичных ошибках — ложные друзья, управление, произношение. Отдельно
проработаны 157 фразовых глаголов и идиом и 17 ложных друзей переводчика.

Слова лежат в `data/_part_*.json` и собираются в `data/words.json`:

```bash
python data/build.py
```

Сборщик проверяет каждую запись: заполненность полей, уникальность id и самих
слов, корректность уровня и — что важнее всего при пополнении — что английские
поля не содержат кириллицы, а русские её содержат, и что нигде не затесались
символы чужих алфавитов. Перепутанные местами поля и случайный иероглиф внутри
русской фразы глазами не ловятся: каждая отдельная запись выглядит правдоподобно.

Чтобы добавить слова, создай новый `data/_part_*.json` того же вида и пересобери
обе цели:

```bash
python data/build.py && python web/build.py && cp data/words.json ios/WordPeek/Resources/words.json
```
